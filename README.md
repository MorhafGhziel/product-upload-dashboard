# Product Upload Dashboard

A responsive React application I built for content creators to efficiently manage and upload product assets. This project showcases my skills with React, TypeScript, and modern web development practices.

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/MorhafGhziel/product-upload-dashboard.git
cd admin-product-upload-tool
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and visit:

```
http://localhost:5173
```
